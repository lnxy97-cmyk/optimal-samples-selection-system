How to Run in Windows:
1. Open the project folder.
2. Navigate to the "dist" directory.
3. Double-click "main.exe".
4. The system will launch automatically.

How to Run in MacOS:
macOS cannot directly run Windows .exe files.
Please open Terminal, go to the project folder, and run:
1. python3 main.py

Usage Instructions:
1. Input the parameters (m, n, k, j, s).
2. Select input method:
   - Random generation
   - Manual input
3. Click "Execute" to generate k-sample groups.
4. View the results displayed on the screen.
5. Click "Store" to save results into the database file.
6. Click "History" to view previously saved records.
7. Use "Display" to load a selected record.
8. Use "Delete" to remove selected records.
